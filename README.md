# Project Kryptos Lab

> An engineering-first investigation into the Kryptos sculpture at CIA Headquarters.

## Purpose

This repository documents reproducible experiments, engineering observations, and cryptographic analysis related to Kryptos.

The goal is **not** to claim a solution.

The goal is to investigate every hypothesis using evidence.

---

# Guiding Principles

1. Facts are separated from hypotheses.
2. Every experiment must be reproducible.
3. Failed experiments are documented.
4. No theory is accepted without evidence.
